## Getting Started

First, clone the repo

Go to folder directory and run 'pnpm i' to locally install required dependencies

Then run 'pnpm run dev' to open application in dev mode

![image](https://github.com/user-attachments/assets/7bb3f71a-c80e-4415-abb8-282e99eb0dd3)

Click on 'Send me a Sample Push'

![SamplePush](https://github.com/user-attachments/assets/f0610f50-dfe7-4127-8cb2-79798c9fd873)

Push message notification should appear after a brief delay
